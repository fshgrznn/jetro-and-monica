# Jetro & Monica Wedding Invitation

This project is a wedding invitation site built with React and Vite.

## Run locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Build for production:
   `npm run build`
